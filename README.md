# CardFighter / 抡语（暂名）

## 📖 项目简介
本项目是一款基于Unity2D开发的 **1D回合制卡牌格斗** 游戏。

玩家在一条线性的1D战斗场景中，通过消耗费用使用卡牌来进行移动、攻击或施放特殊能力。  
每使用一张卡牌即结算一个完整回合，卡牌不需要抽取，也不会从牌库耗尽——更像是一组随时可用的“战斗指令列表”。

---

## 🌏 世界观与背景
游戏设定于一个 **平行世界的春秋战国时代**。  
在这个世界里，诸子百家皆以真实的武力或法术参与战斗，玩家扮演某一学派的弟子，周游列国、切磋技艺。玩家可通过战斗获得更强卡牌，或将已有卡牌合成为更高阶的战斗技巧。
